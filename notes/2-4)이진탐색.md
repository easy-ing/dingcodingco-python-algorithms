# 딩코딩코 Chapter2 - 이진탐색

# **이진 탐색(Binary Search)**

## **1) 한 줄 정의**

- 정렬된 배열(또는 정렬 기준이 있는 자료)에서 **탐색 범위를 절반씩 줄여가며** 원하는 값을 찾는 탐색 방법.

---

## **2) 왜 빠른가?**

매번 탐색 범위를 **절반으로 줄이기 때문**에 비교 횟수가 급격히 줄어듦.

- 예: 원소가 1,000,000개여도
    
    이진 탐색은 대략 **20번 내외( log2(1,000,000) ≈ 20 )** 비교로 찾을 수 있음
    

---

## **3) 핵심 조건(진짜 중요)**

✅ **데이터가 정렬되어 있어야 함 (오름차순/내림차순 명확히)**

정렬이 안 되어 있으면 이진 탐색은 성립하지 않음.

---

## **4) 동작 원리(절차)**

오름차순 정렬 배열 기준:

1. 탐색 구간의 왼쪽 lo, 오른쪽 hi를 잡는다.
2. 중간 인덱스 mid = lo + (hi - lo) / 2 계산
3. arr[mid]와 target 비교
    - 같으면 → 찾음
    - arr[mid] < target → 오른쪽으로 이동 (lo = mid + 1)
    - arr[mid] > target → 왼쪽으로 이동 (hi = mid - 1)
4. lo > hi가 되면 → 못 찾음

---

## **5) 시간/공간 복잡도**

- 시간 복잡도: **O(log N)**
- 공간 복잡도:
    - 반복문 구현: **O(1)**
    - 재귀 구현: **O(log N)** (호출 스택)

---

## **6) Java 구현 (반복문 기본형: 존재 여부/인덱스 찾기)**

```java
public class BinarySearchBasic {

    // target이 있으면 해당 인덱스, 없으면 -1 반환
    public static int binarySearch(int[] arr, int target) {
        int lo = 0;
        int hi = arr.length - 1;

        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2; // overflow 방지

            if (arr[mid] == target) {
                return mid;
            } else if (arr[mid] < target) {
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return -1;
    }

    public static void main(String[] args) {
        int[] arr = {1, 3, 4, 7, 9, 12, 15};
        System.out.println(binarySearch(arr, 7));  // 3
        System.out.println(binarySearch(arr, 8));  // -1
    }
}
```

## **7) 실수 포인트(자주 터지는 부분)**

### **✅ (1)**

### **while (lo <= hi)**

### **vs**

### **while (lo < hi)**

- “존재 여부/인덱스 찾기” 기본은 **lo <= hi**가 안전함
- lo < hi로 쓰면 마지막 한 칸을 체크 못 하는 경우가 생김

### **✅ (2) mid 계산 overflow**

- 안전한 방식: mid = lo + (hi - lo) / 2
- 위험한 방식: mid = (lo + hi) / 2
    
    (lo+hi가 int 범위를 넘을 가능성)
    

### **✅ (3) 정렬 방향**

- 내림차순이면 비교 분기가 반대로 바뀜
    
    (오름차순 기준 코드를 그대로 쓰면 오답)

## **8) “Lower Bound / Upper Bound”**

### **Lower Bound**

정렬된 배열에서 **target 이상(>= target)이 처음 등장하는 위치**

```java
public class LowerBoundExample {

    // arr은 오름차순 정렬
    // target 이상이 처음 나오는 인덱스 반환 (없으면 arr.length)
    public static int lowerBound(int[] arr, int target) {
        int lo = 0;
        int hi = arr.length; // [lo, hi)

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (arr[mid] >= target) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
}
```

### **Upper Bound**

정렬된 배열에서 **target 초과(> target)가 처음 등장하는 위치**

```java
public class UpperBoundExample {

    // arr은 오름차순 정렬
    // target 초과가 처음 나오는 인덱스 반환 (없으면 arr.length)
    public static int upperBound(int[] arr, int target) {
        int lo = 0;
        int hi = arr.length; // [lo, hi)

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (arr[mid] > target) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }
}
```

### **활용: target의 개수 세기**

count = upperBound(arr, target) - lowerBound(arr, target)

## **9) 이진 탐색이 쓰이는 대표 문제 패턴**

- **정렬된 배열에서 값 찾기**
- **중복 원소 범위 찾기 (lower/upper)**
- **정답이 단조(monotonic)하게 변하는 문제에서 최솟값/최댓값 찾기**
    - 예: “가능/불가능”이 경계로 나뉘는 문제(파라메트릭 서치)
