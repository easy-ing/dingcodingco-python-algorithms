## **Q1. 링크드 리스트 끝에서 K번째 값 반환하기**

### **문제 핵심**

- 단일 연결 리스트에서 **뒤에서 K번째 노드의 값**을 구한다.
- 예) 6 -> 7 -> 8, K=2 이면 **7**

### **풀이 아이디어 (투 포인터 / 러너 기법)**

1. fast 포인터를 먼저 **K칸** 이동
2. 이후 fast와 slow를 **같이 한 칸씩** 이동
3. fast가 끝(null)에 도달하면 slow가 **뒤에서 K번째** 위치

### **시간/공간**

- 시간: O(n)
- 공간: O(1)

### **Java 코드**

```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

class Solution {
    // 뒤에서 k번째 값을 반환
    public int kthFromEnd(ListNode head, int k) {
        ListNode slow = head;
        ListNode fast = head;

        // fast를 k칸 먼저 이동
        for (int i = 0; i < k; i++) {
            fast = fast.next; // k는 항상 유효하다고 가정(문제 조건에 맞게)
        }

        // fast가 끝에 닿을 때까지 같이 이동
        while (fast != null) {
            slow = slow.next;
            fast = fast.next;
        }

        return slow.val;
    }
}
```

## **Q2. 배달의 민족: 주문 가능 여부 판별**

### **문제 핵심**

- menus(현재 가능한 메뉴 목록)와 orders(사용자 주문 목록)가 주어질 때
    
    **orders의 모든 항목이 menus에 포함되는지** 확인
    

### **풀이 아이디어 (HashSet)**

- menus를 HashSet으로 만들면 조회가 O(1)에 가까움
- orders를 순회하며 하나라도 없으면 false

### **시간/공간**

- 시간: O(M + O) (메뉴 수 + 주문 수)
- 공간: O(M)

### **Java 코드**

```java
import java.util.*;

class Solution {
    // 모든 주문이 가능한지 여부 반환
    public boolean canOrder(String[] menus, String[] orders) {
        Set<String> menuSet = new HashSet<>(Arrays.asList(menus));

        for (String order : orders) {
            if (!menuSet.contains(order)) return false;
        }
        return true;
    }
}
```

> 

> return canOrder ? "가능" : "불가능"; 처럼 바꾸면 됨.

## **Q3. 더하거나 빼거나 (Target Number)**

### **문제 핵심**

- 배열 numbers가 있고 각 원소 앞에 + 또는 -를 붙여 합을 만든다.
- 합이 target_number가 되는 **경우의 수**를 구한다.
- 예) [1,1,1,1,1], target=3 → 5

---

### **풀이 1) DFS(재귀) 백트래킹 (가장 정석)**

### **아이디어**

- 인덱스 idx에서 선택지는 2개:
    - +numbers[idx]
    - numbers[idx]
- 끝까지 갔을 때 합이 target이면 1 증가

### **시간/공간**

- 시간: O(2^n)
- 공간: O(n) (재귀 스택)

### **Java 코드**

```java
class Solution {
    public int solution(int[] numbers, int target) {
        return dfs(numbers, target, 0, 0);
    }

    private int dfs(int[] numbers, int target, int idx, int sum) {
        if (idx == numbers.length) {
            return (sum == target) ? 1 : 0;
        }

        int plus = dfs(numbers, target, idx + 1, sum + numbers[idx]);
        int minus = dfs(numbers, target, idx + 1, sum - numbers[idx]);

        return plus + minus;
    }
}
```

### **풀이 2) DP(HashMap)로 경우의 수 누적 (확장형)**

### **아이디어**

- 현재 만들 수 있는 합 -> 경우의 수를 Map에 저장
- 다음 숫자를 처리할 때 새 Map으로 갱신
- 중복 합을 자동으로 합쳐서 관리 가능

### **시간/공간**

- 시간: 합의 종류 수를 S라 하면 대략 O(n * S)
- 공간: O(S)
