# 딩코딩코 Chapter3- 정렬 (2)

## **1) 선택 정렬 (Selection Sort)**

### **핵심 개념**

- 배열을 **앞에서부터 하나씩 자리를 확정**해 나가는 정렬
- 매 패스마다 **남은 구간에서 최솟값(오름차순 기준)을 찾아** 현재 위치(i)와 **swap**한다.

### **동작 흐름(오름차순)**

1. i=0 위치에 들어갈 **가장 작은 값**을 0~끝에서 찾기
2. 찾은 최솟값의 인덱스(minIdx)와 i를 swap
3. i=1로 이동해서 1~끝에서 최솟값 찾기 반복

### **특징**

- 시간 복잡도: **항상 O(N²)** (이미 정렬되어 있어도 비교 횟수 거의 동일)
- 공간 복잡도: **O(1)** (제자리 정렬)
- 안정 정렬: **No** (swap 때문에 같은 값의 상대 순서가 깨질 수 있음)
- 장점: 구현 쉽고 swap 횟수는 비교적 적은 편
- 단점: 큰 데이터에 비효율적

### **자바 코드**

```sql
public class SelectionSort {
    public static void selectionSort(int[] arr) {
        int n = arr.length;

        for (int i = 0; i < n - 1; i++) {
            int minIdx = i;

            // i 이후 구간에서 최솟값 찾기
            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[minIdx]) {
                    minIdx = j;
                }
            }

            // 최솟값을 i 위치로 swap
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}
```

### **한 줄 요약**

- **남은 구간에서 최소(또는 최대)를 찾아 현재 위치에 놓는 방식**, 항상 O(N²), **불안정 정렬**

## **2) 삽입 정렬 (Insertion Sort)**

### **핵심 개념**

- 배열을 **앞쪽은 이미 정렬된 구간**이라고 보고,
- 다음 원소(key)를 **정렬된 구간의 알맞은 위치에 “삽입”**한다.

### **동작 흐름(오름차순)**

1. i=1부터 시작 (arr[0]은 정렬된 상태라고 가정)
2. key = arr[i]
3. 정렬된 왼쪽 구간에서 key보다 큰 값들을 **오른쪽으로 한 칸씩 밀기(shift)**
4. key를 빈 자리에 삽입

### **특징**

- 시간 복잡도
    - 최악/평균: **O(N²)**
    - 최선(거의 정렬된 경우): **O(N)** (이게 삽입정렬의 강점)
- 공간 복잡도: **O(1)** (제자리 정렬)
- 안정 정렬: **Yes** (같은 값이면 보통 기존 순서 유지)
- 장점: **거의 정렬된 데이터에 매우 유리**, 구현 간단
- 단점: 역순에 가까우면 느림
